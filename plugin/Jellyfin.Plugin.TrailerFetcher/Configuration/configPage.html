Network

No cookies file uploaded.
Used by yt-dlp for authenticated/age-restricted YouTube access. No browser (Firefox, Chrome, Safari, ...) stores cookies as a plain file you can point to directly - Firefox keeps them in an SQLite database inside its profile folder, not a "cookies.txt". Export one instead: install the "Get cookies.txt LOCALLY" extension (also on the Chrome Web Store; avoid the plain "Get cookies.txt" one, it was pulled as malware), sign in to a YouTube account that's passed age verification, open youtube.com, and use the extension to export the current site's cookies as a Netscape-format cookies.txt - then upload that file here. Saved immediately on upload - not part of the Save button below.
Minimum wait before each yt-dlp request. A large library can add up to many separate requests with no pacing between them, which can trip YouTube's own rate limiting - that then blocks the whole session for up to an hour, with every remaining movie/series failing until it lifts. Lower this only if you're confident it won't happen; 0 disables the delay entirely.
If YouTube rate-limits the session anyway, wait, then retry the rest of the run exactly once instead of stopping immediately. There's no reliable way to know when the limit actually lifts - YouTube's own message only states an upper bound - so this is a single bounded retry, not a backoff loop: if the retry also gets rate-limited, the run stops for good.
How long to wait before that single retry. Defaults to a bit past YouTube's own stated "up to an hour" ceiling - retrying too early just spends the one retry hitting the same still-active limit. Disabled unless "Retry once if rate-limited" above is on.
