Installation

Trailer Fetcher installs through Jellyfin's normal plugin repository mechanism — add the repository once, then install and update it from the Catalog like any other plugin.

1. Add the repository

In Jellyfin: Dashboard → Plugins → Repositories → Add Repository, and enter this URL:

https://raw.githubusercontent.com/grexe/jellyfin-trailer-fetcher/main/plugin/manifest.json

2. Install the plugin

Go to Dashboard → Plugins → Catalog. Trailer Fetcher should now be listed under General — install it.

3. Restart Jellyfin

Required for a newly installed plugin to load.

4. Configure and run

Open Dashboard → Plugins → Trailer Fetcher to configure it (see Configuration for what every setting does), then either wait for its daily scheduled trigger or run it on demand from Dashboard → Scheduled Tasks → Fetch Missing Trailers.

First run tip: turn on Dry run (under Debugging and Testing) for your first pass. It logs exactly what would happen — what it would search for, download, rename, or move — without touching any files, so you can sanity-check the result before letting it write anything.

Updating

Once the repository is added, new versions show up as a normal update in Dashboard → Plugins → My Plugins, the same as any other Jellyfin plugin.

Uninstalling

Dashboard → Plugins → My Plugins, find Trailer Fetcher, and uninstall it from there. Trailers it already downloaded are ordinary local files and are not removed — only the plugin itself and its own configuration/state are.
